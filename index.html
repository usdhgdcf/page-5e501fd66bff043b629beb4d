1. 选定套餐并开通订阅

在套餐区选择基础版、旗舰版或团队版。支付完成后，账户会生成可复制的订阅地址，用于所有兼容客户端。

2. 按设备选择客户端

3. 导入机场订阅

打开客户端的配置、订阅或 Profile 页面，粘贴订阅 URL 并更新。成功后应看到分组节点，而不是空列表。

4. 连接与分流

优先挑选延迟较低或标注 IPLC 的节点。建议开启规则模式：国内网站直连，国际访问走加速。游戏与会议可临时切换低延迟线路。

5. 日常维护

流量将尽时减少大文件下载或升级套餐。更换设备时先在旧设备断开。遇到解析失败，先更新订阅再切换节点，仍异常则通过工单说明客户端名称与系统版本。

常见问题

火箭VPN 是什么？和普通加速器有何不同？

火箭VPN(cnrocket) 采用机场订阅：开通后得到一条可在多款客户端里使用的配置，而不是只能打开某一个封闭应用。你可以按场景换节点、改分流，把网络加速用在办公、学习和娱乐上。

官方客户端下载在哪里？必须用你们的安装包吗？

官网把「客户端选择」作为核心入口。我们指引使用广泛验证的 Clash 系、Shadowrocket、Surge、Stash 等客户端，再导入 cnrocket 订阅。请收藏本站，勿在搜索结果中随便点击仿冒下载页。

三个套餐怎么选？流量和设备如何计算？

轻度使用选基础版（100GB / 3 设备）。需要原生流媒体、游戏 IPLC 和优先支持选旗舰版（300GB / 5 设备）。多人共用或长期大流量选团队版（1000GB / 20 设备）。流量按月重置，设备指同时在线数量。

如何把订阅导入 Clash 或 Shadowrocket？

复制账户中的订阅链接，在 Clash 类软件的配置页选择「从 URL 下载/添加订阅」，在 Shadowrocket 中通过「添加订阅」粘贴同一地址。更新成功后开启代理或 VPN 开关，再选节点连接。

旗舰版的 IPLC 与原生解锁分别解决什么问题？

IPLC 侧重点对点专线时延，更适合对战游戏和实时语音。原生解锁侧重出口网络对常见流媒体平台的识别表现，降低地区验证失败。两者不能替代平台账号本身的地区属性。
